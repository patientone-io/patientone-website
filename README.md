## 🇬🇧 English

Source code for the official website and landing page at **[patientone.uk](https://patientone.uk)**.

Built with a strict lightweight philosophy: zero bulky frameworks, zero client-side tracking, and instant load times.

### ✨ Highlights

- **Static & Fast:** Pure semantic HTML5 styled with Tailwind CSS and modern dark-mode aesthetic.
- **Bilingual [ PL / EN ]:** Client-side language switcher with instant toggling and `localStorage` preference memory.
- **Zero Surveillance:** No analytics scripts, no third-party telemetry, no cookies.
- **Transparent Privacy & Terms:** Includes complete, user-facing [Privacy Policy](privacy.html) and [Terms of Service](terms.html).

### 🛠️ Local Development

No build step or Node.js environment is required. You can preview the website with any static web server:

```bash
# Clone the repository
git clone https://github.com/patientone-io/patientone-website.git
cd patientone-website

# Run a local HTTP server (Python 3)
python3 -m http.server 8080
```

Then visit `http://localhost:8080` in your browser.
